# RenderBatch 1.1.6 — Windows x64

[Tải RenderBatch 1.1.6](https://github.com/duynq202/AutoRender/raw/refs/heads/downloads/renderbatch-templates/downloads/RenderBatch-1.1.6-Windows-x64.zip)

Giải nén toàn bộ rồi chạy `RenderBatch.Windows.exe`. Có sẵn .NET runtime; không cần Python hoặc .NET SDK.

Bản này cho phép kết nối **CapCut 9.7.0** bên cạnh 9.6.0, gồm chuỗi phiên bản có hậu tố build. Đây là cập nhật điều kiện nhận phiên bản; chưa xác minh thao tác GUI trên CapCut 9.7.0 thực tế. Chọn đúng CapCut.exe của bản bạn đang dùng, kiểm tra 6 ảnh nhận diện và học lại mục đã đổi giao diện trước khi thử một project ngắn.

Giữ cơ chế thử mở bảng xuất mỗi 5 giây trong 120 giây; chờ xuất tối đa 180 phút, quét thông báo thành công và file video mỗi 5 giây, không ghi log từng lần quét. Giữ profile và video đã xuất.

60 kiểm thử đạt; build/publish Windows thành công.
